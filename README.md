# Taskraze

Taskraze is an Android application developed in Kotlin as part of my BSc thesis. The thesis documents the application's development and technical implementation.

## Features

- **Firebase integration:** Cloud Firestore and Firebase Realtime Database.
- **Authentication and user management.**
- **Calendar management** and daily schedule planning.
- **In-app chat** functionality.

## Technologies

Kotlin, Firebase, Cloud Firestore, Firebase Realtime Database.
